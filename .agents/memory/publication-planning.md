---
name: Publication planning
description: Rule for showing catalogue items in the public weekly planning
---

Un anime n’apparaît dans le planning public que si l’administration lui attribue explicitement une date de publication.

**Why:** Les publications administrateur doivent être maîtrisées par une date réelle, sans répartir automatiquement les anime non planifiés dans des jours arbitraires.

**How to apply:** Toute nouvelle vue ou modification du planning doit conserver ce filtre et utiliser l’heure enregistrée avec la date. Les données historiques sans date doivent rester masquées du planning.
